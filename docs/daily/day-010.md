# 📖 Notes
1. What is synchronous JavaScript?
Synchronous code executes one operation at a time in order.JavaScript waits for one statement to finish before moving to the next.

2. What is asynchronous JavaScript?
Asynchronous JavaScript allows JavaScript to start a task that takes time and continue doing other work instead of waiting for it to finish.

3. Why do we need asynchronous JavaScript?
Imagine your application requests data from a server.
The server might take:
100ms
500ms
2 seconds
5 seconds
If JavaScript completely stopped while waiting, the webpage would become unresponsive. Asynchronous JavaScript allows the browser to continue working while waiting for slow operations.
Common examples:
-API requests
-Database operations
-Timers
-File operations
-User events
-Network requests

4. What is setTimeout()?
setTimeout() executes a function after at least the specified delay.

-JavaScript
setTimeout(() => {
    console.log("Mission complete");
}, 2000);
The 2000 means approximately 2000 milliseconds = 2 seconds.

setTimeout() does NOT guarantee that the function executes exactly after 2 seconds. It means the callback becomes eligible to run after the delay, subject to the event loop and other work.

5. What is setInterval()?
setInterval() repeatedly executes a function after a specified interval.

6. clearInterval()
clearInterval() stops an interval.

7. What is the Call Stack?
The Call Stack keeps track of functions currently being executed.The most recently added function is executed first. This follows LIFO:Last In, First Out.

8. What are Web APIs?
The browser provides APIs that JavaScript itself doesn't directly execute. The browser handles these operations and later sends their callbacks back into JavaScript's execution process.

9. What is the Event Loop?
The Event Loop continuously checks whether JavaScript is ready to execute waiting callbacks.
Simplified:
JavaScript
    ↓
Call Stack
    ↓
Browser/Web APIs
    ↓
Callback Queue
    ↓
Event Loop
    ↓
Call Stack

10. What is a Promise?
A Promise represents the eventual result of an asynchronous operation.
It can be in three states:
-Pending
The operation hasn't finished.
-Fulfilled
The operation succeeded.
-Rejected
The operation failed.

11. .then()
.then() runs when the Promise succeeds.

12. .catch()
.catch() handles rejection.

13. async
An async function always returns a Promise.

14. await
await waits for a Promise inside an async function. This makes asynchronous code easier to read.

15. What is fetch()?
fetch() is used to make HTTP requests. fetch() returns a Promise.
