# 📖 Notes

## What is an API?

An API (Application Programming Interface) allows two pieces of software
to communicate with each other.

## What is HTTP?

HTTP stands for HyperText Transfer Protocol.
It is commonly used for communication between clients and servers on the web.

## What is an HTTP Request?

An HTTP request is a message sent by a client to a server asking it to
perform an operation.

A request can contain:
- Method
- URL
- Headers
- Body

## HTTP Methods

GET - Retrieve data
POST - Create data
PUT - Update/replace data
DELETE - Delete data

## What does fetch() return?

fetch() returns a Promise that eventually provides a Response object.

## What does response.json() do?

response.json() reads the response body and asynchronously parses JSON
into a JavaScript value such as an object or array.

## What is response.ok?

response.ok indicates whether the HTTP response has a successful status.
It is true for successful HTTP responses and false for unsuccessful ones.

## Does fetch() reject on HTTP 404 or 500?

No. fetch() can resolve with a Response object even when the server
returns an HTTP error such as 404 or 500.

Therefore we should explicitly check response.ok.

## Network Error vs HTTP Error

A network error occurs when communication with the server cannot be
successfully completed.

An HTTP error occurs when communication succeeds but the server returns
an unsuccessful HTTP status such as 404 or 500.
