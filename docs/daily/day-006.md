# 📖 Notes

## What is a loop?
A loop repeatedly executes a block of code until a condition becomes false.
...

## Why do loops exist?
It exists because we don't have to write repetetive codes for the same logic as it will bloat the memory and will reduce the readability of the code.
...

## What is a for loop?
In for loop we initialize,add condition and increment/decrement simultaneously.
...

## What is a while loop?
A while loop keeps running as long as its condition is true. It is useful when you don't know beforehand how many times the loop should execute.

...

## Difference between for and while?
for Use when you know the number of iterations.while Use when you don't know how many times the loop should run.
...

## What is break?
break immediately stops the current loop or switch statement and continues execution after it.
...

## What is continue?
continue skips the current iteration of the loop and immediately moves to the next iteration.
...

## Why are arrays usually used with loops?
Because it is of similar content and through loops we can drastically reduce the amount of code to write for each element of the array instead we can simply pass them through the loops and write the code once.
...

## What is for...of?
for...of is a loop used to iterate over iterable objects like arrays and strings.
...

## Difference between for and for...of?

for is both for html and javascript but for...of is strictly for javascript array.
