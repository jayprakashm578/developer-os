---# 🤔 Reflection

## What did I learn?

I learned how JavaScript handles errors using try, catch, finally and throw.
I also learned how Promise rejection works with async/await.

I understood that try contains code that may fail, catch handles the error,
and finally runs regardless of whether the operation succeeds or fails.

I also learned that new Error() provides useful information such as
error.name, error.message and error.stack.

Most importantly, I learned how to make asynchronous operations fail
gracefully instead of allowing errors to remain unhandled.

## What confused me?

I initially confused Promise rejection with the catch block.
I learned that reject() changes the Promise to the rejected state,
while catch() handles that rejection.

I also need to improve my understanding of exactly what await pauses
and how the event loop continues handling other work.
