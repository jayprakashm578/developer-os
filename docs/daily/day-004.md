# 📖 Notes

What is the DOM?
    -It is a programming interface that represent's a web page strucrture as a tree of objects allowing language like javascript to modify and manipulate the document's content and style dynamically.

Why is it called a tree?
    -Because it uses a hirearchical data structure that mirrors how a naturall tree grows making it a parent-child relationship.

What is a node?
    -A node is any individual object inside the DOM tree. Every HTML element, text, attribute, and comment is represented as a node.

What is the document object?
    -It is the main entry point of the webpage which acts as the root node of the entire dom tree.When a browser loads a website it automatically creates this object to represent the webpage.

Why can't HTML change itself?
    -Because it is not a programming language it is a static markup language.

Why write functions?Why not duplicate code?
    -If you copy massive amount of code if even a tiny error is found now you have to manually change it in all the code but in function you only change it once.
    -Duplicating code reduces the readability of the code the developer hava to read all the code just to understand what the logic behind is but in function the name itself gives away.
    -Functions have great reusability and scalability as function allow to write code once and use it with different inputs.
    -Duplicating code takes too much memory bloating file sizes.But function have smaller code size which results in faster download and also clean, function based code run more efficintly in browser.
