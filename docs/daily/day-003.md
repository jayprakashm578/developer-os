# 📖 Notes

What happens first when the browser opens a webpage?
    -User enters URL
    ↓
    Browser checks cache
    ↓
    DNS Lookup
    ↓
    Gets IP Address
    ↓
    Sends HTTP Request
    ↓   
    Receives HTML
    ↓
    Starts parsing HTML
Why does index.html exists?
    -Because it is the universal default home page the server automatically looks for when a user visits a website domain.
    index.html
    ↓
    Acts as the application's entry point
    ↓
    Loads CSS
    ↓
    Loads main.js
    ↓
    Creates the root application
Why is main.js linked from index.html?
    -Because it serves as the parent root for the entire javascript application.Instead of cluttering all the scripts,css or assets we link only the main.js  because it is an ES module it can use import statement to pull all the css,scripts and assets.
What does type="module" mean?
    -It tell the browser to treat the javascript file as an  ES module instead of traditonal , standard script.Standard script blocks the browser from parsing the HTML document until  the script finished downloading but in module it is deffered by default.
    
# 💡 Key Takeaways

- index.html is the application's entry point.
- main.js starts the JavaScript application.
- ES Modules allow code to be split into reusable files.
- type="module" enables imports and exports.
- Modern projects organize code into modules instead of one large script.
