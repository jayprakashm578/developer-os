# 📖 Notes

1-What is javascript?
    JavaScript is a high-level, interpreted programming language used to create dynamic and interactive web applications.
    It can run in:
    - Web browsers
    - Servers (using Node.js)
    - Desktop applications
    - Mobile applications
    - IoT devices

JavaScript allows developers to manipulate the DOM, handle user interactions, communicate with servers, and build full-stack applications.

2-What is nodejs?
    Node.js is an open-source JavaScript runtime built on Google's V8 JavaScript engine.It allows JavaScript code to run outside the browser by providing access to operating system features like:
    - File system
    - Network
    - Processes
    - Operating system APIs

Difference between Javascript and Node JS-
    -Browsers intentionally restrict JavaScript from accessing the local file system for security reasons Node.js provides its own File System (fs) module, allowing JavaScript programs running on your own computer or server to read and write files safely.
    -Javascript is a programming language and Node js is a runtime environment which runs that language.
    -It can be run anywhere but Node js runs only in a machine's operating system.
    
What is npm?
    Npm stands for Node Package Manager, it is a massive digital warehouse where developers share and download reusable blocks of javascript code.
    -A package is a directory containing pre written, reusable code wrapped in a single folder.

Local dependency vs Global dependency
    -The scope of the local dependency is limited to the project it was  installed in but in case of global you can acces it from any folder.
    -The local dependency is saved in the package.json but the global dependency doesn't have a tracker.
    -Local dependencies are installed inside the project and should be used for almost every application Global dependencies are usually developer tools such as npm, nodemon, or create-vite.

Why don't we download libraries manual anymore?
    -Because of a dependency hell.
    -Modern packages often rely on many mini packages so tracking, downloading all of them manually is impossible.
    -The order of script must be strict if it is in wrong order the site collapses.
    -When downloading file manually you commit massive source files into git repository bloating your code history.

The package.json is the most important file in node js because it acts as a central hub for the entire application. Without it a project cannot be easily shared, installed, updated, or run by other developers.
package.json stores:
- Project metadata
- Scripts
- Dependencies
- DevDependencies
- Version
- License
- Project name

What problem vite solves?
    -Vite solves the problem of slow and sluggish development environment in modern javascript.
    -Before vite during the launch of a development sever first all the javascript code is to be integrated in the package before it can be launched but Vite serves JavaScript modules on demand during development.Instead of bundling the entire application before starting, it loads only the modules required by the browser, making startup almost instantaneous. When a file changes, Vite updates only that module using Hot Module Replacement (HMR), resulting in very fast development.

Create React App became less popular because it grew too slow and couldn't meet the requirements of modern architecture.
