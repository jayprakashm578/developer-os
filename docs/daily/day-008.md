# 📖 Notes

## What is a function parameter?
It is a placeholder variable declared in a function definition it tells function what type of information to expect when it runs.
...

## What is an argument?
It is the actual value you pass when calling a function,it fills in the placeholder.
...

## Difference between parameter and argument?
A parameter is the variable blueprint and the argument is the actual data.
...

## What does return do?
It sends back the data from a function to the main program and stops the execution immediatelly.It makes the function reusable by sending the data to main program we can use the value outside of that function.
...

## Difference between return and console.log()?
-Return hands data back to the program  console.log() prints the text to the screen.
-It is invisible to users but console.log() can be seen in developer console.
-return saves data to the variables console.log() does not affect the code.
...

## What is an arrow function?
It is a type of function expression.
...

## Function declaration vs function expression?
-Function declaration can be called before they appear in the code but in function expression you have to define them to use them.
-Starts with a function keyword but function expression assigned to a variable.
-Function declaration is used for global and reusable functions,function expression used for local logic or callback.
...

## What is a callback?
It is a function passed as an argument inside another function which is then executed inside that outer function at a later time.
...

## What is a higher-order function?
A higher order function is a function that either takes a function as an argument or returns it or does both.
...

## Why are reusable functions important?
They allow to write code once and use it multiple times, which keeps the code base clean and easy to maintain.
-Imporves code readability and easy to testing.
-When you found a bug you have to fix it in only one place not multiple place.
