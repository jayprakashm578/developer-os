# 📖 Notes

What is vite?
    -Vite is a modern frontend build tool and development server that provides fast project startup, Hot Module Replacement (HMR), and optimized production builds.
Why was it created?
    -As JavaScript applications became larger, older tools like Webpack had to bundle the entire application before starting the development server. This increased startup time significantly. Vite solves this by serving ES Modules directly and bundling only when building for production.
What is a dev server?
    -A dev server is a local web server that runs on the computer to host the application during coding.It automatically reloads or updates the application whenever source files change.
What is HMR?
    -It is a software development feature that updates only the changed JavaScript or CSS module inside the running application without reloading the entire page.
Why is vite faster than older toolinga?
    -Vite is faster because it serves javascript modules on demand. Instead of bundling the entire application before starting it only loads the required modules making the startup almost instataneous.
What does npm install do?
    -npm install reads package.json to determine which packages are required. If package-lock.json exists, npm installs the exact versions recorded there to ensure consistent environments across all developers.
What is node modules?
    -node_modules is the directory where npm stores all installed packages and their dependencies required by the project. It is automatically created when npm install is executed.
Why is package-lock.json important?
    -It is important because without it we don't know which version of dependency to download . If we download different versions the same project can behave differently.package-lock.json records the exact versions of every installed dependency and its dependency tree. This ensures every developer installs identical packages, making the project reproducible.



# 💡 Key Takeaways

1. Vite serves ES Modules on demand.
2. npm install downloads project dependencies.
3. node_modules stores installed packages.
4. package-lock.json ensures consistent dependency versions.
5. HMR updates only changed modules without reloading the page.
