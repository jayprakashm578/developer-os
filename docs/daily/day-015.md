# 📖 Notes

## What is Node.js really providing?
Node.js provides a runtime environment for executing JavaScript outside the browser, together with APIs for filesystem access, networking, processes, streams, paths, and other system-level operations.
Node.js
├── JavaScript engine
├── process
├── filesystem
├── path
├── HTTP
├── streams
└── networking

...

## Node.js vs Browser JavaScript
In the browser: console.log(document); works because the browser provides document.

In Node: console.log(document); normally fails because Node doesn't provide the browser's DOM.
But Node provides things such as: console.log(process); and: console.log(globalThis);

This is the key idea:
JavaScript is the language. The runtime determines what APIs are available.
...

## What is process?
process is a Node.js global object that provides information and control over the current Node.js process.
...

## What is globalThis?
JavaScript runtimes provide a global object.
In modern JavaScript: globalThis is the standard way of accessing the global environment.
...

## What is a module?
A module is a separate file containing code that can be imported and used elsewhere.
...

## CommonJS vs ES Modules
Older/common Node.js style:
const fs = require("fs");
module.exports = {
    name: "Developer OS"
};
Import: const data = require("./data");

ES Modules - Modern JavaScript module syntax:
import fs from "node:fs";
Export: export const name = "Developer OS";
...

## What is fs?
fs means file system. It allows Node.js to interact with files and directories. fs is a built-in Node.js module that provides APIs for reading, writing, updating, deleting, and interacting with files and directories.
...

## What is path?
path helps you safely work with files and directory paths.
...

## What is __dirname?
__dirname represents the absolute directory path of the current module/file in CommonJS. It is different from process.cwd(), which represents the directory from which the Node process was started.
process.cwd()
→ D:\Olympus\developer-os

__dirname
→ directory containing the current JavaScript file
...

## What is the Node http module?
The Node.js http module provides APIs for creating HTTP servers and making HTTP requests.
...

## How does createServer() work?
http.createServer() creates and returns an HTTP server. The callback passed to it is executed whenever the server receives an HTTP request, receiving req and res objects.
So: const server = http.createServer((req, res) => {
    // runs for each incoming request
});

The callback itself is not executed just once when the server is created. It executes for incoming requests.
...

## Why does Express exist?
As applications become larger, manually handling everything with the Node http module becomes cumbersome. Express gives you a much cleaner routing and middleware model.
