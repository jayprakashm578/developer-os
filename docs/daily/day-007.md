# 📖 Notes

## What is map()?
It is a javascript tool used that loops through every item in an array and performs a transformation and gives a brand new array without affecting the old array.
...

## What is filter()?
It creates a brand new array only containing the values which passes through a special condition.If zero matches returns an empty array.
...

## What is find()?
It returns the very first value that matches the specific condition.If there is zero matches it returns undefined.
...
    
## What is includes()?
It checks whether the array contains a specific value or not it returns in true or false.
...

## What is forEach()?
It loops the every single item in an array and performs a function for each of them.
...

## Difference between map() and forEach()?
map() transforms data it is used to calculate or alter data it returns a brand new array of the exact same length leaving the orginal array untouched.
forEach() is used to perform side effect like manipulating the DOM, logging to the console or saving to a database.It returns undefined. 
...

## Why are array methods preferred over loops?
Because they make code declarative,readable,less bug-prone and easier to maintain.Another main reason is immutability as these methods creates a brand new array without touching the original array.
Because array methods return new arrays we can string multiple operation in a single place.Doing this with loops requires creating multiple temperory arrays and writing nested code blocks.
