# 📖 Notes
What is Scope?

Scope is the area where a variable can be accessed.
Think of scope like rooms inside a house.
If a variable is inside a room, only people inside that room can use it.

Why does scope exist?
Scope exists to:
Prevent variable conflicts
Protect data
Organize code
Reduce bugs
Without scope every variable would be global.

Global Scope
Variables declared outside every function or block are global.

Function Scope
Variables declared inside a function exist only inside that function.

Block Scope
Variables created using let and const only exist inside their block.

Lexical Scope
A function can access variables from its parent scope.

What is Hoisting?
JavaScript moves declarations to the top before execution.It works because function declaration are hoisted.

What is Temporal Dead Zone (TDZ)?
The time between entering the scope and declaring a let or const variable.
During this time the variable exists but cannot be accessed.

Execution Context-
Whenever JavaScript runs a function, it creates a new execution context.
It stores:
variables
parameters
function calls
value of this

What is a Closure?
A closure is a function that remembers variables from its outer scope even after the outer function has finished executing.

What is this?
this refers to the object that is currently calling the function.
