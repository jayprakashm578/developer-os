# Project Olympus Glossary

## Runtime

Software that executes a program.

---

## Dependency

A package required by another package or application.

---

## Module

A reusable JavaScript file containing code.

---

## Package

A reusable collection of code distributed through npm.

---

## Bundler

A tool that combines application files for deployment.

## Sandbox

A security mechanism that isolates code from the operating system and other applications.

Browsers run JavaScript inside a sandbox to prevent web pages from accessing sensitive files or system resources without permission.
